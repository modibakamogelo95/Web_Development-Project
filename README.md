## Project Overview (complete)
Leap Sports Co. is a fictional, locally owned sports brand founded in 2015. Starting
out by supplying a single local running club, the business has grown to supply
footwear, apparel, and training accessories to amateur athletes and fitness
enthusiasts in the community. This project delivers a functional, responsive,
five-page website for Leap Sports Co., built with semantic HTML5, CSS3, and
vanilla JavaScript, as the Part 1 (Building the Foundation) submission for the
Web Development Introduction PoE.

## Website Goals and Objectives
- Increase brand awareness and online visibility for Leap Sports Co.
- Increase online traffic to a searchable, professional web presence.
- Generate qualified product and stock enquiries through a simple enquiry form.

**Key Performance Indicators (KPIs):**
- Monthly website visitors and page views
- Average time on site
- Number of enquiry/contact form submissions

## Key Features and Functionality
- Responsive navigation with a mobile menu toggle (`js/script.js`)
- Homepage hero, brand "split times" milestone strip, and featured product categories
- About page with company history timeline, mission/vision, and team profiles
- Products page outlining the footwear, apparel, and accessories ranges
- Enquiry page with a client-side validated product/stock enquiry form
- Contact page with two store locations, embedded maps, and a validated contact form

## Design Notes
- **Colour scheme:** Navy (`#101c3d`) and red (`#e4402c`), as specified in the
  Website Project Proposal, plus a warm off-white (`#f5f3ee`) background.
- **Typography:** Anton (bold condensed display face) for headings, Work Sans
  for body text and UI labels.
- **Signature element:** a "split times" milestone strip on the homepage,
  echoing a stopwatch/lap-split display to reflect the running-club origins
  of the brand.
- All product photography is currently placeholder (icon-based cards). Real
  images should be sourced from public domain/Creative Commons libraries or
  original photography before Part 2, and credited below.
